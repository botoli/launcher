# Установка Java с хоста проекта

Начиная с 0.1.8, MSI не входит в EXE. После получения конфигурации backend и успешной синхронизации модов ядро ожидает проверку Java в Desktop. Найденная Java 21 используется сразу. Если Java 21 отсутствует, игроку предлагается скачать и установить её. До согласия сетевого запроса за MSI нет.

## Настройка хоста

Разместите без изменений файл `OpenJDK21U-jdk_x64_windows_hotspot_21.0.3_9.msi` (Eclipse Temurin JDK 21.0.3+9, Windows x64 HotSpot) на публичном HTTPS-хосте без авторизации. Источник исходного файла: [официальный выпуск Adoptium](https://github.com/adoptium/temurin21-binaries/releases/tag/jdk-21.0.3%2B9).

Ожидаемый размер: **179679232 байта**.

Текущий хост проекта: `https://launcher.nevermoreland.ru/download/OpenJDK21U-jdk_x64_windows_hotspot_21.0.3_9.msi`.

SHA-256: `264db89e74213f3ea2d7b7379d1c2ac346797d03b4d88cbf4ce72c3ff96477a1`.

В корневом `launcher-config.json` перед сборкой задайте поле `java21_msi_url` с прямой HTTPS-ссылкой на этот MSI. Значение попадёт во встроенную копию конфигурации. Для переопределения используйте то же поле в `launcher-config.json` рядом с EXE. Старый внешний JSON только с `server_url` наследует адрес MSI из новой сборки. Пустое значение не подменяется: при попытке установки показывается ошибка настройки. Уже установленной Java это не мешает.

Поле меняет только источник файла: версия, размер и SHA-256 закреплены в `crates/launcher-core/src/java_install.rs`. Для перехода на другой MSI нужно обновить эти значения, текст диалога/документацию и выпустить новую версию. Backend `/api/client-config` и ZIP автообновления сохраняют прежний контракт.

## Скачивание и запуск

- Только HTTPS; до пяти HTTPS-перенаправлений. URL с логином/паролем или fragment отвергается. Куки и Telegram-токены не отправляются.
- Подключение ограничено 10 секундами, отсутствие новых данных — 30 секундами. Общего таймаута активной передачи нет.
- Прогресс показывает полученные байты относительно закреплённого размера. `Content-Length` необязателен; если он присутствует, он обязан совпасть с ожидаемым размером.
- Файл сначала сохраняется как `java21.part` в отдельной временной папке. Только после проверки полного размера и SHA-256 он переименовывается в `java21.msi`. Непроверенный файл не запускается.
- До передачи управления Windows Installer загрузку можно отменить в лаунчере. При сетевой ошибке или ошибке целостности доступны повтор и отмена; Minecraft не запускается.
- MSI открывается системным `msiexec.exe` с `/norestart`. Игрок завершает мастер, при необходимости подтверждает UAC и оставляет стандартный каталог установки. Во время работы мастера используется его собственная кнопка отмены.
- После завершения мастера временная папка удаляется, Java проверяется повторно и тот же workflow продолжает подготовку Vanilla/NeoForge. Повторный Play не отправляется. Отмена мастера или отсутствие Java оставляет предложение повтора/отмены.
- Журнал мастера сохраняется в `logs/java-install.log` внутри папки данных лаунчера. Ошибки и отмена загрузки также очищают временный файл. При остановке ожидающего workflow загрузка отменяется; уже запущенный системный мастер принудительно не завершается.

Для backend major, отличных от 21, сохраняется обычная проверка ядра; MSI Java 21 не предлагается. Изменение URL не удаляет установленную Java. MSI не нужен для сборки приложения и не включается в дистрибутив/ZIP автообновления.

Локальные HTTP fixtures проверяют успех с неизвестным Content-Length, неправильные размер/SHA-256, HTTP 404, обрыв, отмену и очистку. Синтетический backend-тест проверяет ожидание ответа Desktop после модов и до запуска Minecraft. Реальная установка Java в тестах не выполняется.
